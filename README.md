## 🌟 What If Your Hand Could Control a Calculator?

No keyboard.

No mouse.

Just show your fingers. 🖐️

**Hand Capture Calculator** is an interactive AI-powered web application that uses computer vision to understand hand gestures and convert them into numbers and actions.

You can also use voice interaction to make the experience more natural.

## 🎥 How It Works

```text
              📷 WEBCAM
                  ↓
           🧠 AI HAND DETECTION
                  ↓
           🖐️ HAND LANDMARKS
                  ↓
          ✋ FINGER DETECTION
                  ↓
             🔢 NUMBER
                  ↓
        ┌─────────┴─────────┐
        ↓                   ↓
   🧮 CALCULATOR        📊 COUNTER
        ↓                   ↓
        └─────────┬─────────┘
                  ↓
             🎤 VOICE
✨ Features
🖐️ 1. AI Finger Detection

Show your hand to the camera and the AI detects your fingers in real time.

☝️  = 1
✌️  = 2
🤟  = 3
🖖  = 4
🖐️  = 5

No buttons required.

🔢 2. Smart Gesture Counter

Every new hand gesture can be added to a running total.

Example:

🖐️  → +5
✌️  → +2
☝️  → +1
🖐️  → +5

Result:

5 + 2 + 1 + 5 = 13
🔥 The smart part

The application doesn't continuously add the same gesture while your hand remains in front of the camera.

Show 🖐️
   ↓
+5

Keep hand there
   ↓
No duplicate counting

Remove hand
   ↓
Show ✌️
   ↓
+2
🧮 3. Gesture-Based Calculator

Use your fingers to interact with mathematical operations.

🖐️ + ✌️

5 + 2

= 7

The goal is to create a more natural human-computer interaction experience.

🎤 4. Voice Commands

Don't want to touch the screen?

Just speak.

Example commands:

"Start counting"

"Stop counting"

"Reset"

"What is the total?"

The application can respond using voice feedback.

🔊 5. AI Voice Reading

When voice reading is enabled:

🖐️

5 fingers detected.

🔊 "5 added. Total is 13."

Voice reading can be turned ON/OFF independently.

🎙️ 6. Separate Voice Controls

The application provides separate controls for:

🎤 Voice Commands
🔊 Voice Reading

This means:

Voice Commands OFF

The application doesn't listen for commands.

Voice Reading OFF

The application stays silent.

Camera

Finger detection can continue independently.

📷 7. Live Webcam + Virtual Simulator
Live Webcam

Use your real camera:

📷 → 🖐️ → AI → Number
Virtual Hand

Don't have a camera?

No problem.

Use the built-in simulator:

0 → 1 → 2 → 3 → 4 → 5

This makes the application easy to test anywhere.
